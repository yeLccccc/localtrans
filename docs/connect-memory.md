# 连接记忆（mem）机制

> "mem" 指连接记忆制（M3a FR5）：LocalTrans 会记住你**成功连接过**的设备，
> 在应用启动或会话意外断开时自动、静默地重连，直到成功或判定对端不在线。
> 本文说明它的数据结构、生命周期、退避算法与设计取舍。

## 分层：core 管数据，壳层管编排

```
crates/localtrans-core/src/connect_memory.rs   ← 数据结构 + 持久化 + 退避纯函数（可测）
src-tauri/src/reconnect.rs                     ← 编排：启动扫描 / 断连触发 / 退避循环
```

与全项目一致的原则：**纯函数下沉 core，编排留在壳层**。退避序列、回落
判定、抖动都是 core 里可单测的纯函数；壳层拿着 discovery/session 的全量
上下文决定"何时试、怎么试"。

## 数据结构

单条记忆只存两个时间戳，按指纹（64 位 hex）索引：

```json
{ "entries": { "<fingerprint-hex>": { "first_connected_at": 1730000000,
                                       "last_connected_at": 1730009999 } } }
```

- 落盘在 `data/connect_memory.json`，原子写；`BTreeMap` 保证键序稳定
  （文件 diff 友好，格式有单测钉死）。
- **刻意不存设备名、地址、权限**——那些分别属于发现缓存、信任表；记忆
  只回答一个问题："这台设备我连过吗？"
- 文件缺失或损坏一律重置为空表，不 panic——记忆是**尽力持久化**的体验
  优化，丢了不影响任何正确性（大不了不自动重连）。

### 为什么独立成文件，而不塞进 trusted_peers.json？

信任表会被外部夹具（E2E 测试的 seedTrust）整文件重写，附加字段会被静默
丢弃。独立文件让**记忆与信任的生命周期解耦**：配对关系由信任表管，记忆
由壳层在"移除信任"时显式清除，互不牵连。

## 生命周期

1. **登记**：一次成功会话建立后 `record(fp)`——新设备入表返回 true，
   老设备仅续期 `last_connected_at`（首连时间不变）。
2. **启动扫描**：应用启动时对全部"已记忆 + 仍受信 + 未在会话"的设备逐台
   调度重连。此刻发现表多半还是空的——循环自带等待分支，无需提前。
3. **断连触发**：会话意外断开（SessionDown）时调度；满足"记忆 + 信任 +
   未在会话 + 未在重连中"才生效（防重入）。
4. **退避循环**：见下节。重连复用生产路径 `connect_pinned`（证书指纹
   钉扎），单次尝试 10 秒超时——防止死地址（对端掉电）把节奏拖到 QUIC
   idle 上限。
5. **清除**：移除信任时壳层先清记忆再断开；重连成功后记忆自然续期。

## 退避算法

第 `n` 次连续失败后的等待秒数（±20% 抖动）：

```
backoff(n) = min(2 * 2^(n-1), 30)   →  2 / 4 / 8 / 16 / 30 / 30 / 30 …
give_up(n) = n >= 5                  →  连续 5 次失败后停止主动重试
jitter(base, r) = round(base × [0.8, 1.2])，至少 1s
```

- 抖动防止多台设备在同一时刻同步冲击对端；下限 1s 防止退化成热轮询。
- **发现表里没有对端地址 ≠ 失败**：对端可能整机休眠了几个小时。没有地址
  就等待 discovery 更新，不计入失败次数——所以"对端休眠半天后上线，
  会话自动恢复"是成立的。
- 回落停止后转入**静默监视**：设备从发现表消失又重新出现（absent→present
  跃迁）时，重新武装一轮新的重连周期，语义等同启动扫描。

## 静默与不打扰

- 全程只有两条 toast：重连成功、最终放弃。中间的 2/4/8/16/30 秒等待
  对用户完全不可见。
- 与手动连接不抢路：自动重连与手动 connect 走同一条 `connect_pinned`，
  重复建连由会话代次机制幂等覆盖。
- 中结名册里独有（本地发现不可见）的设备交给独立的 relay 自愈回路，
  两条回路互不抢占。

## 测试覆盖

- 退避序列精确断言（2/4/8/16/30…、0 次防御、极大入参不溢出）
- 5 败回落边界（4 次仍试、第 5 次停）
- 抖动上下界、中点回归、越界/NaN 钳制、最小 1s
- 持久化 roundtrip：落盘→重载全量还原、重复登记不覆盖首连时间、
  清除后不复活
- 文件缺失 / 损坏 → 空表不 panic
- 落盘 JSON 格式钉死测试（字段名、嵌套结构）
