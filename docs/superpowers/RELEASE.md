# LocalTrans v1.0 发版定义（RELEASE）

> 2026-09-07 与产品所有者对齐定稿。本文回答两个问题：**这条路走到头是什么样**（最终形态）、
> **怎么知道走到了**（出口条件）。一切开发工作以本文为北极星；
> `BACKLOG.md` 退化为出口条件①的展开清单，不再新增范围。

## 一、最终形态（用户视角）

### 第一天（装机）
- PC：绿色单文件 exe，双击即用，数据跟 exe 走；手机：装 APK，默认目录就绪。
- 同一局域网几秒互见；连接→同意→6位码→配对，此后"已连接"。

### 每天（局域网 PC↔PC，核心场景）
- 开机即连（连接记忆制）；卡片显示通道状态。
- 推送三途径（拖放/向导/直推按钮）；接收 Ask/Auto；秒传。
- 浏览共享区→多选下载=1张父卡；本地排序。
- 传输卡：暂停/继续/取消/重试；父子展开；双进度（已发/对方确认）；积压提示；
  活动分区+历史折叠；两级删除（视图移除 vs 彻底删除+磁盘历史找回）。
- 断点续传跨重启；并发闸门+排队位次；同对端串行。

### 出差/异地（跨网 PC↔PC，智能选路）
- 自建中继（端到端加密，零知识）。
- 名片：本机地址一键复制（全部网卡+公网出口+中继），粘贴即添加→跨网段/AP隔离可发现。
- 评分选路（RTT50%+带宽35%+稳定15%，迟滞≥15）；网络切换原子换通道，传输不断。
- 卡片通道标签（直连·2ms / 经中继·120ms）+通道面板；强制走中继排障开关。

### 手机在环（PC↔phone）
- 相册/文件即选即推；接收免烦恼；完成通知+跳转。
- 传输管理与 PC 同构（父卡/暂停取消/历史/排队）——三端一个心智。

### 底层承诺
QUIC+mTLS 钉扎 / 配对码防暴力 / 路径防穿越 / 隐身 / 日志红线 /
单实例 / 优雅关机 / 磁盘真相源（强杀不丢账）。

### v1.0 不做（防"永远在完善"，进 v1.1 池）
聊天、剪贴板同步、云存储、自动更新、托盘、系统通知中心、相册备份（v0.8 已下线）。

## 二、出口条件（全部满足才按发版键）

1. **功能完备**：上述最终形态 100% 落地（对照定案 specs：智能选路三段/设备页散项/手机对齐/中继场景）。
2. **质量门**：场景库 run-all 全绿——含零信任冷启动、中继路径、L3 重置、三端门禁（core 串行为准）；无 P0/P1 遗留。
3. **发布工程**：安装包（PC/手机）、版本号三处同步、CHANGELOG、数据兼容声明（v0.12 起单向升级）。
4. **文档齐**：用户文档、relay 自建部署文档（已有）、已知限制清单。
