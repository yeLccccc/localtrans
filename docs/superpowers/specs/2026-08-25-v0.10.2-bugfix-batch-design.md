## 逐项方案

### 01 隐身模式修复(语义:不出现在任何"发现"渠道;主动连接仍可用)

**隐身的完整语义**(修复后):
- 不广播 Presence(已实现,保留)
- 不应答对端探测(已实现,保留)
- **不上报中结名册**(新增:名册里看不到你)
- **不主动发探测**(新增:ProbeNow/ProbeAddr 门控)
- 你仍能:被动听到局域网 Presence(≤5s 看到别人)、收到中结名册(看到远程设备)、主动连接任何设备。主动连接时对方自然感知到连接本身——这是合理代价,不属于"被发现"。

实现:
1. **协议**:`RelayMsg::Register` 加 `hidden: bool`(serde default=false,兼容旧客户端);relay server 收到后正常登记连接(可被 punch),但**名册广播(RosterUpdate)剔除 hidden 条目**——半隐身:自己看得到名册,名册看不到自己。
2. **客户端**:`RelayClientConfig` 加 `hidden: bool`(启动时快照);`set_hidden()` 切换时若中继已连接→重启中继连接重新注册(复用 v0.9.0 save_settings"改名自动重连"机制)。PC(commands.rs set_hidden)与 FFI(lib.rs set_hidden)同构接线。
3. **探测门控**:discovery.rs 命令循环 `DiscoveryCmd::ProbeNow`/`ProbeAddr` 分支加 `if cfg.hidden` 检查,隐身时不发送。connect_device 内部路径若依赖探测需豁免(实现时验证 connect 不走这两个命令分支;连接会暴露 IP 给目标,与隐身语义不冲突)。
4. **PC UI 提示**:隐身开启时"手动添加设备"提交与"立即探测"入口提示"隐身模式下已暂停主动探测"(若对应入口存在;仅提示不强禁)。

### 02 下拉菜单加宽(纯 CSS)

DeviceCard.vue:`.dropdown-menu min-width: 230px → 280px`;`.dropdown-item select max-width: 110px → 130px`。

### 03 PC 配对成功即时刷新卡片

main.rs `PairingResult` 分支:`ok:true` 时除现有逻辑外,立即执行与 SessionUp 分支相同的设备列表重建+emit(connected_fps 插入、merge_devices、emit "device-list" + "connection-state")——双保险,SessionUp 迟到/丢失时配对成功事件本身完成刷新。抽公共函数避免两处复制。

### 04 配对收尾时序修复 + A 侧兜底

1. **core 时序调整**(session.rs:1256-1267 Matched 分支):先 `send_all(PairResult{ok:true})` 给对端,**再**本地 complete_pairing + 本地 PairingResult 事件——网络回包最先发出,对端不会因本地收尾耗时/连接竞争而错过。FailedOut/Mismatch 分支已是先回包,不变。现有 E2E(双方 PairingResult ok:true,到达顺序不限)回归保护。
2. **Android A 侧超时兜底**:进入 CODE_ENTRY 状态时启动倒计时(复用设置页"连接安全"超时值,默认 60s),超时仍停在 CODE_ENTRY → FAILED("等待对端确认超时")并展示。PairingUiState 加 deadlineEpochMs。
3. **错误不再静默**:DevicesViewModel.submitPairingCode/connectDevice 的空 catch 改为写入 pairing.reason / uiState.error,失败可见。

### 05 Android ANR 修复(FFI 调用全部下 IO 线程)

- 四个 Ffi Repo 实现(FfiDevicesRepo/FfiTransfersRepo/FfiFilesRepo/FfiSettingsRepo):所有同步 FFI 方法体包 `withContext(Dispatchers.IO)`(接口不变,调用方零改动,单测 Fake 不受影响)。
- FilesScreen.kt:936/1022 LaunchedEffect 内 `app.devices()` → `withContext(Dispatchers.IO){ app.devices() }`。
- 验证:装机高频操作(设备页刷新/文件页切换/传输中切页)logcat 无 ANR;既有单测回归。

### 06 IP 输入框溢出(纯 CSS)

Devices.vue `.form-input` 加 `box-sizing: border-box`。

### 07 长按菜单"发送到设备"(Android)

- FileEntryMenuSheet 本机分支加 MenuRow(Icons.Default.Send,"发送到设备"),签名加 `onSend: () -> Unit`;远程分支不变(保持只读)。
- FilesScreen 接线:onSend → 将该文件路径置入当前 Tab 选中集(单元素)→ showDeviceSheet=true → 复用现有设备选择+pushFilesRel 发送流;发送发起后清选中。四 Tab(相册/视频/文档/全部)同构。
