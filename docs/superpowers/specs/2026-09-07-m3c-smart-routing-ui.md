# Spec M3c: 智能选路·呈现与设备页收尾（ui）

> 里程碑：M3 第 3 段。依赖 M3a/M3b 数据与逻辑。
> 一句话：用户看得到的最后一块——通道标签/面板/排障开关，外加设备页遗留小项。

## 目标
通道状态可视、可查、可干预。

## 范围
**做**：FR1-FR4（PC+手机两端同步）。**不做**：新页面（全部挂设备页）。

## 功能需求
- **FR1 通道标签**：设备卡地址行改为「直连 · 2ms」（绿）/「经中继 · 120ms」/「未知」（离线常驻卡）；数据源=M3b 通道记录；点击进面板。
- **FR2 通道面板**：每地址一行（`192.168.1.5  2ms  ~940Mbps  ✓当前使用` / `经 relay  120ms  ~85Mbps`），含最近探测时间与手动"重测"按钮。
- **FR3 强制走中继**：卡片 ⋮ 菜单开关（排障后门）；开启时 connect 强制中继通道；状态在卡上可见角标。
- **FR4 设备页收尾**：卡片独立「推送」按钮（直开向导步 2，机制已通只差入口）；本机 IP 徽章升级名片一键复制（M3a FR3 的 UI 面）。

## 验收标准
1. 通道标签三态真机截图目检（直连/中继/离线各一）；
2. 面板数据与评分记录一致性断言（e2e 读通道表对照）；
3. 强制中继开→场景断言会话 viaRelay=true→关→恢复直连；
4. 手机端同构目检（传输页/设备页通道标签）。

## 依赖与顺序
依赖 M3b。完成后 M3 整站关门（场景库全绿）。

## 风险
- 面板数据刷新节奏（避免高频重渲）——复用既有事件驱动+防抖模式。
