# Spec P4: 打磨·性能基线与优化（polish-performance）

> 节奏位：第三段第 4 站（最后一个功能性 spec，其后 RC）。
> 一句话：快得有数——每个性能面有基线、有门禁、不回退。

## 目标
建立性能基线并优化到位，形成发版性能报告。

## 范围
**做**：FR1-FR5。**不做**：协议大改。

## 功能需求
- **FR1 直连吞吐基线**：千兆局域网单文件大吞吐场景（≥1GB）测基线（MB/s）、CPU%、内存；与历史对照不回退（写进 run-all 性能档）。
- **FR2 中继吞吐**：经 relay 的吞吐/延迟基线（relay 单机带宽上限标注）。
- **FR3 小文件批量**：1000×10KB 场景的吞吐与卡片渲染（M3b 探测开销复检）。
- **FR4 前端性能**：1000+ 卡片列表滚动/更新流畅度（4Hz 全表泵下的丢帧感）；必要时虚拟滚动。
- **FR5 后台足迹**：空闲态（无传输）CPU≈0、无周期性磁盘扫描；传输中后台 CPU 有界。
- **FR6 性能门禁**：基线数据入 run-all 报告，回归超阈值(±20%)标红。

## 验收标准
1. 性能基线报告（三网×典型负载矩阵）归档进发版文档；
2. 空闲足迹断言场景绿；
3. 1000 卡片场景渲染可接受（目检+时长断言）。

## 依赖与顺序
依赖 V 段（复用场景设施）；与 P3 并行可行。其后 RC。

## 风险
- 性能优化与 P1 视觉改动耦合——P1 先行，P4 在其上测；
- 基线受测试机状态影响——固定机型/时段复测 3 次取中位。
