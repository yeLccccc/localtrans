# 浏览页设计(分歧定案)

> 日期:2026-08-30
> 版本基线:v0.11.0
> 状态:已与用户逐项确认(brainstorming)
> 关联:传输域定案(specs/2026-08-30-transfer-page-design.md)——E-f 与其父卡片定案联动;设备页定案(specs/2026-08-30-device-identity-network-design.md)——刷新按钮删除一致性。

## 0. 背景

浏览页功能树梳理(基于 Browse.vue 核实)产出七个分歧点 E-a~E-g,用户逐项裁定。浏览页现状骨架健康(设备 chips/共享区栏/面包屑/分页/多选下载/推送静默刷新/断连提示),本轮只做减法与联动,不重构骨架。

## 1. 定案:E-a 远程文件操作 —— UI 不做,后端保留

- **裁定:没必要、不合理**——浏览对方共享是只读消费场景,远程改对方文件超出产品定位(传文件,不是远程文件管理器)。
- 前端不提供重命名/删除/新建目录入口。
- **后端能力保留不删**:ShareRename/ShareDelete/ShareMkdir 协议消息、权限门(S6)、删除确认门(S7/S8/S9)、Android 端入口,全部维持现状(已有测试覆盖,不动)。将来若变主意只需加 PC UI。

## 2. 定案:E-b 文件预览 —— 砍

- 不做内嵌预览(图片/文本点击预览)。
- 要看先下载,系统默认程序打开——本地体验更完整。

## 3. 定案:E-c 搜索/过滤 —— 砍

- 不做搜索框,也不做前端本地子串过滤。
- 大目录靠翻页 + 排序(§4)覆盖找文件需求;协议加远程搜索是大动作,不值。

## 4. 定案:E-d 列表排序 —— 前端本地排序

- 排序维度可切换:名称 / 大小 / 修改时间,升降可切;默认**目录优先 + 名称升序**。
- 纯前端实现:对当前目录已加载条目排序,零协议改动。
- 分页"加载更多"追加后按当前排序重排。

## 5. 定案:E-e 下载另存为 —— 砍

- 下载全走全局下载目录(设置页可改全局值)。
- 不做逐任务目录选择;与传输域"父卡片+历史记录"模型一致(落盘位置确定,卡片可"打开所在文件夹")。

## 6. 定案:E-f 批量下载 —— 发批次 + 父卡片(与传输域联动)

- 现状缺陷:选 N 项逐文件发 N 个任务 → 传输页 N 张独立卡片;与传输域"父卡片"定案冲突。
- 定案:浏览页"下载选中"改为**发一个批次**(文件+文件夹混合清单一次提交)→ 传输页**一张父卡片**(子文件展开、整批控制、失败子项单独重试)。
- 后端:start_download_batch 命令(或复用 dir-pull 编排扩展为多根清单);批次 ID 即父卡片 ID。
- 文件夹 hover「下载」(整棵直拉)同样归一为单条目批次。

## 7. 定案:E-g 刷新按钮 —— 两个都删

- 共享区栏、文件栏两个手动刷新按钮删除。
- 依据:共享变化有 SharesChanged 推送自动刷(500ms 防抖+静默);断连重连有补刷;切换目录/共享区/设备即重拉,天然兜底。
- 与设备页(删刷新)、传输页(删刷新)三页一致:全事件驱动,无手动刷新。

## 8. 保持现状确认(梳理核实,零改动)

- 设备选择栏:已配对∩在线候选、切换局部 spinner、空态引导。
- 面包屑:↑上级/根段/逐段跳层(最后段不可点)。
- 分页:cursor 式加载更多。
- 联动:对方共享变化静默刷(空闲检测,不与用户操作打架);断连 toast"列表可能不是最新";重连自动补刷;"响应通道被占用"友好提示。
- 多选:checkbox 逐个勾选 + 底部"已选 N"浮出栏。

## 9. 三端分布

| 层 | 改动 |
|---|---|
| core | 无新协议(批次编排复用现有 dir-pull 机制扩展多根清单) |
| PC 壳 | start_download_batch 命令(批次清单→父卡片编排) |
| PC UI | 删两处刷新按钮;排序控件(名称/大小/时间/升降);下载选中改发批次 |
| Android | 排序同步;批量下载发批次同步(其子文件展开已有先例) |

## 10. 明确砍掉/否决

| 项 | 理由 |
|---|---|
| 远程文件操作 UI | 用户裁定:没必要不合理;浏览是只读消费 |
| 文件预览 | 下载后系统打开更完整 |
| 搜索/过滤(含本地过滤) | 翻页+排序覆盖;协议搜索是大动作 |
| 另存为 | 与父卡片/历史记录模型冲突;保持简单 |
| 保留刷新按钮 | 三页一致全事件驱动;切换即重拉兜底 |

## 11. 验收要点

1. 浏览页无任何刷新按钮;对方改共享 → 当前目录 5s 内静默更新。
2. 排序:默认目录优先+名称升序;点大小/时间列切换;升降可切;加载更多后保持排序。
3. 选 3 文件+2 文件夹点下载 → 传输页出现 1 张父卡片,展开见 5 个子条目各自进度;整批取消有效。
4. 文件夹行 hover 下载 → 1 张父卡片(该文件夹为唯一子项树的批次)。
5. 下载落盘全部在全局下载目录;完成后"打开所在文件夹"直达。
6. 远程重命名/删除/新建目录:PC UI 无入口;Android 现状入口不受影响(后端协议未动)。
