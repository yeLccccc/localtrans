# Spec M3a: 智能选路·地基（名片/多地址/会话域散项）

> 里程碑：M3 第 1 段。节奏位：功能实现第 3 站之一。
> 一句话：把"设备在哪里、有哪些路"搞清楚——名片与多地址是选路的一切前提；
> 顺手消化会话域定案散项（连接记忆制/TrustBroken/静默期/隐身语义）。

## 目标
1. 本机感知全部地址；relay 回报公网出口；
2. 名片一键复制/粘贴即加——跨网段与 AP 隔离的发现兜底；
3. 会话域四散项落地。

## 范围
**做**：FR1-FR6。**不做**：探测/评分/切换（M3b）、通道 UI（M3c）。

## 功能需求
- **FR1 全网卡枚举**：core 新增 `local_addresses()`（带接口名/网段标注），替代 `primary_local_ip` 单选暴露面（单选保留为兼容别名）；`get_network_status` 与 FFI 镜像扩展为列表。
- **FR2 relay 公网出口回报**：`RegisterAck` 增 `observed_addr` 字段（relay 唯一改动），客户端存入本机地址池。
- **FR3 名片**：`{设备名, 指纹, 全部地址[], 公网出口?, 中继地址?}` 文本格式定义（人可读+程序可解析）；生成与解析进 core；IP 徽章一键复制名片全文。
- **FR4 手动添加粘名片**：解析名片→多地址全部入重探表（每 8s 保活，10 败淘汰）；IP:端口旧格式继续支持。
- **FR5 连接记忆制**：用户主动连过（成功会话）的设备记入持久表；启动与断线后自动重连，退避 2/4/8/16s 封顶 30s，连续 5 败回落停止；配对成功自动连接一次。
- **FR6 会话散项**：TrustBroken（移除信任发协议通知→对端即时降级徽章+toast+断开）；静默期广播间隔 5s→15s（无对端活跃时）；隐身语义修正（只约束被看见，出站探测放行）。

## 验收标准
1. 名片跨网段互加场景：模拟隔离（防火墙挡广播）→粘名片→发现→配对→传输全绿；
2. 断线自动重连场景：杀对端→重启→退避节奏断言→会话恢复；
3. TrustBroken 场景：A 移除→B 即时降级断开；隐身修正单测（出站探测发出）；
4. 上述全部并入 run-all。

## 依赖与顺序
依赖 M1（场景地基）。M3b 依赖本 spec FR1/FR2。

## 风险
- 多网卡环境（VPN/Hyper-V）枚举噪声——过滤策略：排除虚拟网卡（接口名黑名单）；
- 重连风暴（多设备同时退避）——加抖动。
