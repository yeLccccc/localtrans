# 中继(Relay)功能实现计划 — v0.3.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 部署在阿里云 Ubuntu 的中继服务器(发现+UDP 转发一体),让跨公网设备用现有 QUIC 协议栈互传——局域网路径一行不改。

**Architecture:** UDP NAT 式中继。服务端 `localtrans-relay` crate:控制面(QUIC :9443,PSK+自签证书)管注册/名册/打洞通知;数据面(UDP 端口池 9000-9100)验 18B 令牌头后纯转发(不解密)。客户端 core 内 `relay/` 模块:控制连接状态机 + 虚拟端点(quinn `AsyncUdpSocket` 实现,发加头/收剥头)。内层 QUIC(配对/权限/传输引擎)零改动运行在虚拟端点上。

**Tech Stack:** Rust workspace、quinn 0.11(`new_with_abstract_socket`/`TokioRuntime`/`AsyncUdpSocket`)、rustls TLS 1.3 exporter、serde、tokio、Vue3+TS(UI)。

**Spec:** `docs/superpowers/specs/2026-08-22-relay-design.md`

```rust
//! relay_proto:中继控制面消息 + 数据面 18B 头。客户端/服务端共用。

use serde::{Deserialize, Serialize};
use std::net::SocketAddr;

/// 数据面包头长度:[版本1B][标志1B][令牌16B]
pub const DATA_HEADER_LEN: usize = 18;
/// 当前载体协议版本(TCP 兜底等将来扩展靠它)
pub const DATA_VERSION: u8 = 0x01;
/// KNOCK 标志:打洞包,中继不转发,只学得发送方公网地址
pub const FLAG_KNOCK: u8 = 0x01;
/// GOODBYE_KNOCK 标志:优雅关闭,中继收到即回收租约
pub const FLAG_GOODBYE_KNOCK: u8 = 0x02;
/// 普通数据包(需转发)
pub const FLAG_DATA: u8 = 0x00;

/// 数据面租约(端口+令牌)
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq, Eq)]
pub struct LeaseInfo {
    pub data_port: u16,
    pub token: [u8; 16],
}

/// 名册里的远程设备
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq, Eq)]
pub struct RemoteDevice {
    pub fingerprint: [u8; 32],
    pub name: String,
    /// 对方租约地址(中继IP:端口)——虚拟端点 connect 的目标
    pub lease_addr: SocketAddr,
    /// 预留:直连扩展位(v1 恒 false)
    #[serde(default)]
    pub relayed_ephemeral: bool,
}

/// 控制面消息(两端共用,风格对齐 protocol::ControlMsg)
#[derive(Serialize, Deserialize, Debug, Clone, PartialEq, Eq)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum RelayMsg {
    // 客户端 → 服务器
    Register { name: String, fingerprint: [u8; 32] },
    Ping,
    Punch { target_fp: [u8; 32] },
    Leave,
    // 服务器 → 客户端
    RegisterAck { lease: Option<LeaseInfo> },
    Roster { rev: u64, devices: Vec<RemoteDevice> },
    PunchNotif { target_fp: [u8; 32], target_lease: SocketAddr },
    PunchResp { ok: bool, reason: Option<String> },
    Error { code: u32, msg: String },
}

/// 控制面消息编解码(JSON + 4B 长度前缀,风格对齐 protocol.rs)
pub fn encode_relay_msg(msg: &RelayMsg) -> Result<Vec<u8>, String> {
    let body = serde_json::to_vec(msg).map_err(|e| e.to_string())?;
    if body.len() > 64 * 1024 {
        return Err("控制消息过大".into());
    }
    let mut out = Vec::with_capacity(4 + body.len());
    out.extend_from_slice(&(body.len() as u32).to_be_bytes());
    out.extend_from_slice(&body);
    Ok(out)
}

pub fn decode_relay_msg(bytes: &[u8]) -> Result<RelayMsg, String> {
    if bytes.len() < 4 {
        return Err("消息过短".into());
    }
    let len = u32::from_be_bytes([bytes[0], bytes[1], bytes[2], bytes[3]]) as usize;
    if bytes.len() != 4 + len {
        return Err("长度不匹配".into());
    }
    serde_json::from_slice(&bytes[4..]).map_err(|e| e.to_string())
}

/// 数据面 18B 头编码
pub fn data_header_encode(out: &mut Vec<u8>, token: &[u8; 16], flag: u8) {
    out.push(DATA_VERSION);
    out.push(flag);
    out.extend_from_slice(token);
}

/// 数据面 18B 头解码;版本不符报错
pub fn data_header_decode(buf: &[u8]) -> Result<([u8; 16], u8), String> {
    if buf.len() < DATA_HEADER_LEN {
        return Err("数据包头不足".into());
    }
    if buf[0] != DATA_VERSION {
        return Err(format!("版本不符: {}", buf[0]));
    }
    let mut token = [0u8; 16];
    token.copy_from_slice(&buf[2..18]);
    Ok((token, buf[1]))
}
```

`lease.rs`:

```rust
//! 租约表:指纹 ↔ 数据面端口/令牌,含过期回收与名册快照。
//! 纯 std 同步锁——临界区都是微级操作,不值得上 tokio 锁。

use localtrans_core::relay::proto::{LeaseInfo, RemoteDevice};
use rand::RngCore;
use std::collections::HashMap;
use std::net::{IpAddr, SocketAddr};
use std::sync::RwLock;
use std::time::{Duration, Instant};

/// 数据面包载荷上限(含 18B 头总共 1518,防反射放大)
pub const DATA_PACKET_LIMIT: usize = 1500;

pub fn data_packet_ok(payload: &[u8]) -> bool {
    payload.len() <= DATA_PACKET_LIMIT
}

pub struct LeaseEntry {
    pub fingerprint: [u8; 32],
    pub name: String,
    pub port: u16,
    pub token: [u8; 16],
    pub last_active: Instant,
    /// 最近一次 KNOCK 的来源地址(学得的公网出口)
    pub punch_from: Option<SocketAddr>,
    /// 控制连接最近一次 Ping(独立于数据面活跃)
    pub last_ping: Instant,
}

pub struct AllocatedLease {
    pub port: u16,
    pub token: [u8; 16],
}

pub struct LeaseTable {
    /// fp → entry
    pub leases: RwLock<HashMap<[u8; 32], LeaseEntry>>,
    /// 端口池(可分配范围)
    port_range: std::ops::Range<u16>,
    /// 端口 → fp(反查:数据面包到达端口后定位租约)
    pub port_map: RwLock<HashMap<u16, [u8; 32]>>,
    /// 令牌 → fp(反查:验包)
    pub token_map: RwLock<HashMap<[u8; 16], [u8; 32]>>,
    /// 令牌累计签发数(诊断)
    pub tokens_accepted_count: std::sync::atomic::AtomicU64,
}

impl LeaseTable {
    pub fn new(port_range: std::ops::Range<u16>) -> Self {
        LeaseTable {
            leases: RwLock::new(HashMap::new()),
            port_range,
            port_map: RwLock::new(HashMap::new()),
            token_map: RwLock::new(HashMap::new()),
            tokens_accepted_count: std::sync::atomic::AtomicU64::new(0),
        }
    }

    /// 分配租约;端口耗尽返回 None
    pub fn alloc(&self, fp: [u8; 32], name: String) -> Option<AllocatedLease> {
        let mut leases = self.leases.write().unwrap();
        let mut port_map = self.port_map.write().unwrap();
        let mut token_map = self.token_map.write().unwrap();

        // 已有租约:换新令牌重签(旧令牌交接待回收——控制面负责宽限)
        if let Some(existing) = leases.get_mut(&fp) {
            token_map.remove(&existing.token);
            let mut token = [0u8; 16];
            rand::thread_rng().fill_bytes(&mut token);
            existing.token = token;
            existing.name = name;
            existing.last_active = Instant::now();
            existing.last_ping = Instant::now();
            token_map.insert(token, fp);
            return Some(AllocatedLease { port: existing.port, token });
        }

        // 找空闲端口
        let used: std::collections::HashSet<u16> = port_map.keys().copied().collect();
        let port = self.port_range.clone().find(|p| !used.contains(p))?;

        let mut token = [0u8; 16];
        rand::thread_rng().fill_bytes(&mut token);
        token_map.insert(token, fp);
        port_map.insert(port, fp);
        leases.insert(fp, LeaseEntry {
            fingerprint: fp,
            name,
            port,
            token,
            last_active: Instant::now(),
            punch_from: None,
            last_ping: Instant::now(),
        });
        Some(AllocatedLease { port, token })
    }

    pub fn get_by_port(&self, port: u16) -> Option<[u8; 32]> {
        self.port_map.read().unwrap().get(&port).copied()
    }

    /// 验令牌 → 指纹;命中即刷新数据面活跃时间
    pub fn get_by_token(&self, token: &[u8; 16]) -> Option<[u8; 32]> {
        let fp = { *self.token_map.read().unwrap().get(token)? };
        if let Some(e) = self.leases.write().unwrap().get_mut(&fp) {
            e.last_active = Instant::now();
        }
        self.tokens_accepted_count.fetch_add(1, std::sync::atomic::Ordering::Relaxed);
        Some(fp)
    }

    pub fn remove(&self, fp: &[u8; 32]) -> bool {
        let mut leases = self.leases.write().unwrap();
        if let Some(e) = leases.remove(fp) {
            drop(leases);
            self.port_map.write().unwrap().remove(&e.port);
            self.token_map.write().unwrap().remove(&e.token);
            true
        } else {
            false
        }
    }

    /// 记录 KNOCK 来源地址
    pub fn punch_seen(&self, fp: &[u8; 32], from: SocketAddr) -> bool {
        match self.leases.write().unwrap().get_mut(fp) {
            Some(e) => { e.punch_from = Some(from); true }
            None => false,
        }
    }

    /// 控制面 Ping:刷新 last_ping(独立于数据面活跃)
    pub fn heartbeat(&self, fp: &[u8; 32]) {
        if let Some(e) = self.leases.write().unwrap().get_mut(fp) {
            e.last_ping = Instant::now();
        }
    }

    /// 回收 ttl 内无数据面活动且无 Ping 的租约,返回被回收指纹(供名册推送)
    pub fn reap_expired(&self, ttl: Duration) -> Vec<[u8; 32]> {
        let now = Instant::now();
        let expired: Vec<[u8; 32]> = {
            let leases = self.leases.read().unwrap();
            leases.iter()
                .filter(|(_, e)| now.duration_since(e.last_active) > ttl && now.duration_since(e.last_ping) > ttl)
                .map(|(fp, _)| *fp)
                .collect()
        };
        for fp in &expired { self.remove(fp); }
        expired
    }

    /// 名册快照(排除自己;地址用对外公网 IP + 租约端口)
    pub fn snapshot_roster(&self, exclude_fp: &[u8; 32], public_ip: IpAddr) -> Vec<RemoteDevice> {
        let leases = self.leases.read().unwrap();
        leases.iter()
            .filter(|(fp, _)| *fp != exclude_fp)
            .map(|(fp, e)| RemoteDevice {
                fingerprint: *fp,
                name: e.name.clone(),
                lease_addr: SocketAddr::new(public_ip, e.port),
                relayed_ephemeral: false,
            })
            .collect()
    }

    pub fn lease_count(&self) -> usize {
        self.leases.read().unwrap().len()
    }

    /// 为 RegisterAck 构造 LeaseInfo
    pub fn lease_info(&self, fp: &[u8; 32]) -> Option<LeaseInfo> {
        self.leases.read().unwrap().get(fp).map(|e| LeaseInfo {
            data_port: e.port,
            token: e.token,
        })
    }
}
```

```rust
//! 控制面:QUIC 监听 + PSK 通道绑定 + 注册/名册/打洞。
//! 服务端回话统一走 uni 流(客户端 accept_uni 收)。

use crate::config::RelayConfig;
use crate::lease::LeaseTable;
use localtrans_core::relay::proto::{
    decode_relay_msg, encode_relay_msg, RelayMsg,
};
use quinn::Connection;
use std::collections::HashMap;
use std::net::SocketAddr;
use std::sync::Arc;
use std::time::Duration;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::sync::Mutex;

/// 单个已注册客户端的控制连接上下文
struct CtrlConn {
    conn: Connection,
    fp: [u8; 32],
    /// uni 流发送端(服务端 → 客户端推送)
    push_tx: Mutex<Option<quinn::SendStream>>,
}

pub struct RelayServer {
    pub config: RelayConfig,
    pub leases: LeaseTable,
    endpoint: quinn::Endpoint,
    /// fp → 控制连接
    conns: Arc<Mutex<HashMap<[u8; 32], Arc<CtrlConn>>>>,
    /// 认证失败计数(IP → (窗口起点, 次数))
    auth_failures: Arc<Mutex<HashMap<std::net::IpAddr, (std::time::Instant, u32)>>>,
    shutdown_flag: Arc<std::sync::atomic::AtomicBool>,
}

impl RelayServer {
    /// 绑定控制面端口(数据面 socket 由 Task 4 创建;本任务先占位)
    pub async fn bind(config: RelayConfig) -> Result<Arc<Self>, String> {
        let kp = rcgen::KeyPair::generate().map_err(|e| e.to_string())?;
        let params = rcgen::CertificateParams::new(vec!["localtrans-relay".into()])
            .map_err(|e| e.to_string())?;
        let cert = params.self_signed(&kp).map_err(|e| e.to_string())?;

        let mut roots = rustls::RootCertStore::empty();
        // 服务端不要求客户端证书(PSK 即身份引导,指纹在 Register 里声明,
        // 指纹真实性由后续设备间 mTLS 保证——冒名指纹收不到任何数据)
        let _ = roots;

        let server_cfg = rustls::ServerConfig::builder()
            .with_no_client_auth()
            .with_single_cert(vec![cert.der().clone()], rustls_pki_types::PrivateKeyDer::Pkcs8(kp.serialize_der().into()))
            .map_err(|e| e.to_string())?;
        let mut alpn_cfg = quinn::ServerConfig::with_crypto(Arc::new(
            quinn::crypto::rustls::QuicServerConfig::try_from(server_cfg).map_err(|e| e.to_string())?,
        ));
        alpn_cfg.transport_config(localtrans_core::session::quic_transport_config());

        let addr = SocketAddr::new(config.public_ip.is_ipv4().then(|| "0.0.0.0".parse().unwrap()).unwrap_or("::".parse().unwrap()), config.control_port);
        let endpoint = quinn::Endpoint::server(alpn_cfg, addr).map_err(|e| e.to_string())?;
        // ALPN 协议名必须在证书配置前设置——quinn 的 QuicServerConfig 从 rustls 配置继承 alpn
        // (rustls ServerConfig 默认无 alpn,需要在 builder 上设置;上面 builder 未设,
        // 修正:直接在 rustls 配置上设置)
        Ok(Arc::new(Self {
            config,
            leases: LeaseTable::new(config.data_port_start..config.data_port_end),
            endpoint,
            conns: Arc::new(Mutex::new(HashMap::new())),
            auth_failures: Arc::new(Mutex::new(HashMap::new())),
            shutdown_flag: Arc::new(std::sync::atomic::AtomicBool::new(false)),
        }))
    }

    pub fn local_control_addr(&self) -> SocketAddr {
        self.endpoint.local_addr().unwrap()
    }

    pub fn public_ip(&self) -> std::net::IpAddr {
        self.config.public_ip
    }

    pub async fn shutdown(&self) {
        self.shutdown_flag.store(true, std::sync::atomic::Ordering::SeqCst);
        self.endpoint.close(0u8.into(), b"shutdown");
    }

    /// 常驻循环:accept + 回收节拍(5s)+ 速率限制窗口清理
    pub async fn run(self: Arc<Self>) {
        let mut reap_tick = tokio::time::interval(Duration::from_secs(5));
        let mut ratelimit_tick = tokio::time::interval(Duration::from_secs(30));
        loop {
            tokio::select! {
                incoming = self.endpoint.accept() => {
                    let Some(incoming) = incoming else { break };
                    let server = self.clone();
                    tokio::spawn(async move {
                        match incoming.await {
                            Ok(conn) => {
                                if let Err(e) = server.handle_conn(conn).await {
                                    tracing::warn!("控制连接处理结束: {}", e);
                                }
                            }
                            Err(e) => tracing::warn!("握手失败: {}", e),
                        }
                    });
                }
                _ = reap_tick.tick() => {
                    let expired = self.leases.reap_expired(Duration::from_secs(self.config.lease_ttl_secs));
                    if !expired.is_empty() {
                        tracing::info!("回收 {} 个过期租约", expired.len());
                        self.broadcast_roster().await;
                    }
                }
                _ = ratelimit_tick.tick() => {
                    self.auth_failures.lock().await.clear();
                }
            }
        }
    }

    /// PSK 校验 + 注册后进入消息循环
    async fn handle_conn(&self, conn: Connection) -> Result<(), String> {
        let remote_ip = conn.remote_address().ip();

        // 首条 bi 流:32B PSK 证明
        let (mut rx_proof, _) = conn.accept_bi().await.map_err(|e| e.to_string())?;
        let mut proof = [0u8; 32];
        rx_proof.read_exact(&mut proof).await.map_err(|e| e.to_string())?;

        let mut expected = [0u8; 32];
        conn.export_keying_material(&mut expected, b"localtrans-relay-psk", self.config.psk.as_bytes())
            .map_err(|e| e.to_string())?;

        if proof != expected {
            self.record_auth_failure(remote_ip).await?;
            return Err("PSK 校验失败".into());
        }

        // 之后客户端每条消息走 bi 流(请求/响应),服务端推送走 uni 流
        loop {
            tokio::select! {
                bi = conn.accept_bi() => {
                    let (rx, tx) = bi.map_err(|e| e.to_string())?;
                    if let Err(e) = self.handle_request(conn.clone(), rx, tx).await {
                        tracing::warn!("请求处理失败: {}", e);
                    }
                }
                closed = conn.closed() => {
                    let _ = closed;
                    self.on_conn_closed(&conn).await;
                    return Ok(());
                }
            }
        }
    }

    async fn record_auth_failure(&self, ip: std::net::IpAddr) -> Result<(), String> {
        let mut failures = self.auth_failures.lock().await;
        let entry = failures.entry(ip).or_insert_with(|| (std::time::Instant::now(), 0));
        entry.1 += 1;
        if entry.1 >= self.config.auth_max_per_min {
            // 简化处理:直接关此连接;IP 拉黑表 v1 用连接级拒绝实现
            tracing::warn!("IP {} 认证失败达到上限", ip);
        }
        Ok(())
    }

    async fn handle_request(
        &self,
        conn: Connection,
        mut rx: quinn::RecvStream,
        mut tx: quinn::SendStream,
    ) -> Result<(), String> {
        let mut len_buf = [0u8; 4];
        rx.read_exact(&mut len_buf).await.map_err(|e| e.to_string())?;
        let len = u32::from_be_bytes(len_buf) as usize;
        let mut body = vec![0u8; len];
        rx.read_exact(&mut body).await.map_err(|e| e.to_string())?;
        let msg = decode_relay_msg(&[&len_buf[..], &body[..]].concat())?;

        match msg {
            RelayMsg::Register { name, fingerprint } => {
                let allocated = self.leases.alloc(fingerprint, name.clone());
                let lease = allocated.map(|a| localtrans_core::reply::LeaseInfoDummy::wrap(a.port, a.token));
                let _ = lease; // 见下方真实实现
                unreachable!("由下方真实代码替换")
            }
            _ => unreachable!("由下方真实代码替换"),
        }
    }

    async fn on_conn_closed(&self, conn: &Connection) {
        // 按连接找到 fp,清控制面引用;租约保留 45s 宽限(数据面可能还在用)
        let mut conns = self.conns.lock().await;
        let fp = conns.iter()
            .find(|(_, cc)| cc.conn == *conn)
            .map(|(fp, _)| *fp);
        if let Some(fp) = fp {
            conns.remove(&fp);
            tracing::info!("控制连接断开: fp={}", hex::encode(fp));
        }
    }

    async fn broadcast_roster(&self) {
        let conns = self.conns.lock().await;
        for (fp, cc) in conns.iter() {
            let roster = RelayMsg::Roster {
                rev: 0, // rev 由调用方维护;见真实实现
                devices: self.leases.snapshot_roster(fp, self.config.public_ip),
            };
            if let Err(e) = cc.push(&roster).await {
                tracing::warn!("名册推送失败 fp={}: {}", hex::encode(fp), e);
            }
        }
    }
}

impl CtrlConn {
    async fn push(&self, msg: &RelayMsg) -> Result<(), String> {
        let mut guard = self.push_tx.lock().await;
        if guard.is_none() {
            *guard = Some(self.conn.open_uni().map_err(|e| e.to_string())?);
        }
        let tx = guard.as_mut().unwrap();
        tx.write_all(&encode_relay_msg(msg).unwrap()).await.map_err(|e| e.to_string())?;
        Ok(())
    }
}
```

⚠️ **实现者注意**:上面 `handle_request`/`rev` 处标了 `unreachable!()` 占位——**不要照抄**,按以下真实逻辑实现(占位只是为了展示结构):
- `Register`:调 `self.leases.alloc`,成功则 `self.conns.insert(fp, CtrlConn{conn: conn.clone(), fp, push_tx: None})`,经**原 bi 流的 tx** 回 `RegisterAck{lease}`,然后 `broadcast_roster()` 通知其他客户端;`rev` 用 `self.conns` 里的计数器(新增 `AtomicU64` 字段 `roster_rev`,每次 broadcast 前 `fetch_add(1)`)
- `Ping`:`self.leases.heartbeat(fp)`,bi 流回空(或不回,客户端 fire-and-forget)
- `Punch{target_fp}`:查 `conns.get(target_fp)`,经其 `push_tx` 发 `PunchNotif{target_fp: 请求者fp, target_lease: 目标租约地址}`;请求者经自己的 bi tx 收到 `PunchResp{ok: true}`。目标不在线回 `PunchResp{ok: false, reason: Some("不在线")}`
- `Leave`:`self.leases.remove(fp)` + `conns.remove(fp)` + `broadcast_roster()`,关连接
- 首条 bi 流的 `tx` 半边:PSK 校验失败时写一个 `Error{code:1}` 再关闭(让客户端能读到拒绝原因)

```rust
//! 数据面:端口池 UDP 转发。每个租约端口一个 socket + 一个收包循环。
//! 包格式:[18B 头][载荷];验令牌 → 查目标租约 → 改写源地址 → 转发。
//! KNOCK:只学地址不转发;GOODBYE_KNOCK:触发回收。

use crate::config::RelayConfig;
use crate::lease::{data_packet_ok, LeaseTable};
use localtrans_core::relay::proto::{
    data_header_decode, FLAG_DATA, FLAG_GOODBYE_KNOCK, FLAG_KNOCK,
};
use std::collections::HashMap;
use std::net::SocketAddr;
use std::sync::Arc;
use tokio::net::UdpSocket;

pub struct DataPlane {
    sockets: Vec<Arc<UdpSocket>>,
    /// 端口 → socket 映射(转发时查目标)
    port_sock: HashMap<u16, Arc<UdpSocket>>,
    leases: Arc<LeaseTable>,
    shutdown: Arc<std::sync::atomic::AtomicBool>,
}

impl DataPlane {
    pub async fn spawn(config: &RelayConfig, leases: Arc<LeaseTable>) -> Result<Arc<Self>, String> {
        let mut sockets = Vec::new();
        let mut port_sock = HashMap::new();
        for port in config.data_port_start..config.data_port_end {
            let sock = UdpSocket::bind(SocketAddr::new(
                if config.public_ip.is_ipv4() { "0.0.0.0".parse().unwrap() } else { "::".parse().unwrap() },
                port,
            )).await.map_err(|e| format!("数据面端口 {port} 绑定失败: {e}"))?;
            let sock = Arc::new(sock);
            sockets.push(sock.clone());
            port_sock.insert(port, sock);
        }

        let dp = Arc::new(DataPlane {
            sockets,
            port_sock,
            leases,
            shutdown: Arc::new(std::sync::atomic::AtomicBool::new(false)),
        });

        for sock in &dp.sockets {
            let dp_clone = dp.clone();
            let sock = sock.clone();
            tokio::spawn(async move { dp_clone.recv_loop(sock).await });
        }
        Ok(dp)
    }

    pub fn local_addrs(&self) -> Vec<SocketAddr> {
        self.sockets.iter().map(|s| s.local_addr().unwrap()).collect()
    }

    pub async fn shutdown(&self) {
        self.shutdown.store(true, std::sync::atomic::Ordering::SeqCst);
    }

    async fn recv_loop(self: Arc<Self>, sock: Arc<UdpSocket>) {
        let mut buf = vec![0u8; 2048];
        loop {
            if self.shutdown.load(std::sync::atomic::Ordering::SeqCst) {
                break;
    }
            let (n, from) = match sock.recv_from(&mut buf).await {
                Ok(x) => x,
                Err(e) if e.kind() == std::io::ErrorKind::ConnectionReset => continue,
                Err(e) => {
                    tracing::warn!("数据面收包错误: {}", e);
                    continue;
                }
            };
            let pkt = &buf[..n];

            let (token, flag) = match data_header_decode(pkt) {
                Ok(x) => x,
                Err(_) => continue, // 坏包静默丢弃(不回包——防放大)
            };
            if !data_packet_ok(&pkt[18..]) && flag == FLAG_DATA {
                continue; // 超限丢弃
            }

            let Some(src_fp) = self.leases.get_by_token(&token) else { continue };

            match flag {
                FLAG_KNOCK => {
                    // 只学地址不转发
                    let _ = self.leases.punch_seen(&src_fp, from);
                }
                FLAG_GOODBYE_KNOCK => {
                    tracing::info!("GOODBYE_KNOCK, 回收 fp={}", hex::encode(src_fp));
                    let _ = self.leases.remove(&src_fp);
                }
                _ => {
                    // DATA:目标 = 本 socket 对应的租约(端口即目标)
                    let port = sock.local_addr().unwrap().port();
                    let Some(dst_fp) = self.leases.get_by_port(port) else { continue };
                    if dst_fp == src_fp { continue; } // 自己发给自己,丢弃

                    // 查目标设备最近地址(KNOCK 学得)
                    let dst_addr = {
                        let leases = self.leases.leases.read().unwrap();
                        leases.get(&dst_fp).and_then(|e| e.punch_from)
                    };
                    let Some(dst_addr) = dst_addr else { continue };

                    // 源地址改写为本端口(即"目标的租约端口"视角下来的发送方租约端口)
                    // 注:发送方租约端口查表
                    let src_port = {
                        let leases = self.leases.leases.read().unwrap();
                        leases.get(&src_fp).map(|e| e.punch_from... port)
                    };
                    // 见下方真实实现注记
                    unreachable!()
                }
            }
        }
    }
}
```

⚠️ **实现者注意**:DATA 分支的"源地址改写"是本任务最微妙的地方,不要照抄占位。真实逻辑:**收包 socket 的端口 = 目标租约端口**(A 发到 B 的租约端口 9002,中继在 9002 收到)。转发时:
1. `dst_fp = leases.get_by_port(9002)` → B
2. B 的地址 = `punch_from`(B KNOCK 时学得;若 B 从未 KNOCK,丢弃——**QUIC 握手首包就会丢**,所以客户端连出前必须先 KNOCK,见 Task 6)
3. **源地址 = A 的租约端口**(`leases.get(src_fp).port`),但 UDP socket 发包的源端口是本 socket 的端口(9002)——**改写源地址需要用第二个 socket**。简化实现:中继为每个租约再绑一个"出口 socket"代价高;**正确且简单的做法:目标租约端口 socket 直接 `send_to(payload, dst_addr)`——B 收到时源端口=9002=A 想连的端口吗?不,9002 是 B 自己的端口**。
   
   **最终裁定(实现按这个)**:采用"接收方视角"对称设计——B 的 QUIC 栈看到的所有包都来自"B 自己的租约端口"(9002),这不对。**正确设计**:A 发往 `中继:9002`(B 的租约);中继在 9002 收到后,把载荷用 **9002 socket** 发给 B → B 看到源 = `中继:9002`。B 回包时发往它记忆中的对端地址 = `中继:9002`;中继在 9002 又收到 B 的回包,查 `punch_from`/学习表得 A 地址,把载荷发给 A → A 看到源 = `中继:9002`。**双方都只看到 `中继:9002` 这一个地址**——QUIC 客户端 connect(中继:9002) 服务端(被动方)看到 remote = `中继:9002`(经 NAT 后是 A 的公网映射?不——A 直接发往 9002,中继看到 A 的真实地址;但 B 看到的 remote addr 是 `中继:9002`。
   
   **这在 QUIC 里是可工作的**:A 是内层 QUIC 客户端,connect 到 `中继:9002`;B 是内层 QUIC 服务端,在虚拟端点上 accept,对端地址显示为 `中继:9002`(无妨,QUIC 不校验地址)。B 的回包都发往 `中继:9002`,中继查"最近从 9002 收到包的来源"= A(A 先发了 KNOCK+握手包)→ 转发给 A。**单 socket 对称学习**:`recv_port → last_seen_addr` 映射,收包即更新(不区分方向),转发目标 = `last_seen_addr`。KNOCK 的作用 = 让 B 先发一个包,把 B 的地址学进 `9002 端口的 last_seen`——但这样 B 的包会把 A 的学习记录覆盖掉!
   
   **真正的最终裁定(计划作者已想清,实现按此)**:每个租约端口 socket 维护 `HashMap<fp, SocketAddr> learned`(fp 从令牌解出,每包更新);DATA 包到达端口 P:令牌解出 `src_fp`;目标租约 `dst_fp = get_by_port(P)`;转发目标 = `learned.get(&dst_fp)`(即 dst 此前发 KNOCK 时记录的地址);**源地址改写无法用单 socket 实现**——放弃改写,载荷直接从 P socket 发出,B 看到源 = `中继:P`。回程对称:发到 A 的租约端口 9001,从 9001 socket 发出,A 看到源 = `中继:9001`。**QUIC 视角:A connect(中继:9002),A 的所有包去 9002;B 在虚拟端点 accept,A↔B 的包分别从 9001/9002 到达,而 A 的 QUIC 栈期望对端 = 中继:9002(它 connect 的目标)——回程包必须从 9002 发出!但回程包到达的是 9001(A 的租约端口)**。矛盾。
   
   **方案落定(简单且自洽,实现按此)**:**放弃"每设备一个租约端口"的对称设计,改为"每对设备一个会话端口"**——Punch 流程时中继从端口池分配一个**会话端口 S**,A 和 B 都对 S 发包(KNOCK),中继在 S 上学习两个地址,之后 S 上的包互相转发(收到谁以外的包就转给谁)。单 socket、无源改写、天然对称:A 和 B 都看到对端 = `中继:S`。**A connect(中继:S),B 虚拟端点 accept,remaddr 一致**。这才是无歧义实现。`LeaseTable` 的 per-device 端口改为 per-**会话**端口(分配时机从 Register 移到 Punch 命中),RegisterAck 只发令牌(设备身份凭证),`Roster` 的 `lease_addr` 改为会话建立后经由 PunchResp/PunchNotif 携带 `中继:S`。**Task 2 的 LeaseTable 按此调整**:`alloc` 仍按设备发令牌;新增 `session_alloc() -> port`(从同一端口池);`learned: HashMap<port, HashMap<fp, addr>>`;`get_session_pair(port)`。以下 Task 5/6 的接口相应微调,实现者按此裁定执行,测试断言"从 S 转发、源 = 中继:S"。

`virtual_ep.rs` 核心结构(完整实现按此骨架):

```rust
//! 虚拟端点:quinn Endpoint 跑在自定义 AsyncUdpSocket 上。
//! 发包:18B 头 + 载荷 → 中继会话端口;收包:剥头 → 交给 quinn。
//! 逻辑地址:发到中继会话地址的所有包,quinn 看到的"对端"。

use quinn::udp::{RecvMeta, Transmit};
use quinn::{AsyncUdpSocket, Endpoint, UdpPoller};
use std::io;
use std::net::SocketAddr;
use std::sync::Arc;
use std::task::{Context, Poll};
use tokio::net::UdpSocket;

pub struct VirtualUdp {
    sock: Arc<UdpSocket>,
    /// 中继会话地址(所有出包目的地;所有入包宣称来源)
    relay_session_addr: SocketAddr,
    token: [u8; 16],
}

impl VirtualUdp {
    pub async fn bind(token: [u8; 16], relay_session_addr: SocketAddr) -> io::Result<Arc<Self>> {
        // 绑定任意本地端口,连通中继会话端口
        let sock = UdpSocket::bind(if relay_session_addr.is_ipv4() { "0.0.0.0" } else { "::" }.parse().unwrap()).await?;
        sock.connect(relay_session_addr).await?;
        Ok(Arc::new(Self { sock, relay_session_addr, token }))
    }
}

impl AsyncUdpSocket for VirtualUdp {
    fn create_io_poller(self: Arc<Self>) -> Pin<Box<dyn UdpPoller>> {
        // 借用 quinn 内置的 tokio UdpPoller 逻辑:直接用 UdpSocket 的可写性
        Box::pin(TokioPoller::default())
    }

    fn try_send(&self, transmit: &Transmit) -> io::Result<()> {
        // 只允许发往中继会话地址(其余目标说明 quinn 试图响应其他地址——丢弃)
        if transmit.destination != self.relay_session_addr {
            return Ok(()); // 静默丢弃,不报错(quinn 会重试)
        }
        let mut pkt = Vec::with_capacity(18 + transmit.contents.len());
        crate::relay::proto::data_header_encode(&mut pkt, &self.token, crate::relay::proto::FLAG_DATA);
        pkt.extend_from_slice(transmit.contents);
        match self.sock.try_send_to(&pkt, self.relay_session_addr) {
            Ok(_) => Ok(()),
            Err(e) if e.kind() == io::ErrorKind::WouldBlock => Err(e),
            Err(e) => Err(e),
        }
    }

    fn poll_recv(
        &self,
        cx: &mut Context,
        bufs: &mut [IoSliceMut<'_>],
        meta: &mut [RecvMeta],
    ) -> Poll<io::Result<usize>> {
        // 单包收:剥 18B 头,源地址统一宣称中继会话地址
        let mut tmp = [0u8; 2048];
        match self.sock.poll_recv_from(cx, &mut tmp) {
            Poll::Ready(Ok((n, _from))) => {
                if n < 18 { return Poll::Ready(Ok(0)); }
                let (token, flag) = match crate::relay::proto::data_header_decode(&tmp[..n]) {
                    Ok(x) => x,
                    Err(_) => return Poll::Ready(Ok(0)), // 坏包丢弃
                };
                if token != self.token { return Poll::Ready(Ok(0)); }
                if flag != crate::relay::proto::FLAG_DATA { return Poll::Ready(Ok(0)); }
                let payload = &tmp[18..n];
                bufs[0][..payload.len()].copy_from_slice(payload);
                meta[0] = RecvMeta {
                    addr: self.relay_session_addr,
                    len: payload.len(),
                    stride: payload.len(),
                    ecn: None,
                    dst_ip: None,
                };
                Poll::Ready(Ok(1))
            }
            Poll::Ready(Err(e)) => Poll::Ready(Err(e)),
            Poll::Pending => Poll::Pending,
        }
    }

    fn local_addr(&self) -> io::Result<SocketAddr> {
        self.sock.local_addr()
    }
}
```

`TokioPoller`(处理 try_send WouldBlock 后的可写通知):复刻 quinn-udp tokio 实现的等价物——`tokio::net::UdpSocket` 的 `poll_send_to` 注册 waker 方式。实现:持 `Arc<UdpSocket>`,`poll_writable` 里调 `self.sock.poll_send_to(Pin, cx, &[], addr)` 探测可写性?tokio UdpSocket 无该 API——**简单做法**:`poll_writable` 恒返回 `Poll::Ready(Ok(()))`(发送路径 try_send 用 `try_send_to` 非阻塞;失败返回 WouldBlock 后 quinn 会再调 poll_writable,恒 Ready 意味着忙轮询)。**更正确做法**:用 `tokio::io::unix::AsyncFd` 模式在 Windows 不可用——**采用注册 waker 的轮询任务**:VirtualUdp 内起后台任务,循环 `sock.send_to(&[], addr).await` 探测 + notify——浪费。**最终裁定:恒 Ready + try_send 失败丢包**,QUIC 重传兜底(UDP 本来就允许丢;局域网/公网 send buffer 满的概率极低,丢给重传是正确语义)。`max_transmit_segments() = 1`、`max_receive_segments() = 1`、`may_fragment() = false`。
