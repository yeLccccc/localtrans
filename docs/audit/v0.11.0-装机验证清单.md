# v0.11.0 装机双机验证清单

> 代码侧 23 任务已完成,协议硬切换——**三端须同步升级**(PC exe + Android APK + relay 二进制)。

## 部署顺序
1. 服务器:上传 dist/localtrans-relay-v0.11.0-ubuntu-x86_64.tar.gz,二进制覆盖 + systemctl restart(配置不动;WSL 新工具链首产物,建议先冒烟启动)
2. 两台设备:PC 装 win-x64 zip 的 exe;手机装 APK(versionCode 15)
3. 旧版 data/ 目录原地保留,直接覆盖运行

## 已知注意事项
- 混合版本(旧端+新端)不互通属预期——硬切换
- 推送确认超时/拒绝后,对端不能再探测你已有哪些文件(秒传 oracle 已修,仅接受时生效)
- relay 日志默认只记摘要,NAT 轨迹已降 debug
