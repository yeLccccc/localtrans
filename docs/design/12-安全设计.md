# 12 安全设计(全链路汇总)

> 本文汇总 v0.8.2 安全加固批次(S1-S10)与 v0.11.0 审计修复(S1-S7/M-B/M-C)后的完整安全面。

## 1. 威胁模型

- 局域网内恶意设备:伪造身份/重放发现包/探测他人文件/路径攻击/暴力配对码。
- 公网恶意客户端(对自建中继):PSK 猜测/资源耗尽(连接占位/放大反射)/名册探测。
- 恶意对端(已配对后):路径穿越/文件名攻击/超大目录/偏移扩展/越权请求。
- 物理接触产物:从分发包/日志/错误消息中提取隐私。

## 2. 身份与信任

| 机制 | 实现 |
|---|---|
| 设备身份 | Ed25519 + 自签证书;指纹 = SHA256(cert.der);身份文件原子写、key 先 cert 后 |
| 连接认证 | mTLS 双向证书;直连/中继内层均自签验证(issuer==subject+自验签+时间窗) |
| 指纹钉扎 | 已知指纹时握手期强制比对(FingerprintVerifier / PinnedClientCertVerifier)—— 消除"握手后才比对"窗口 |
| 信任写入 | 码验证为真即最高事实,兜底写信任(BUG03);幂等 |
| fail-closed | 信任表无记录 → Perms::denied() 全拒;移除信任即断开+即时生效(S5) |

## 3. 配对

| 机制 | 实现 |
|---|---|
| 明文码不出 B 屏幕 | 码只显示在 B 的 UI;协议只传码本身(单次),B 侧只存哈希;日志无明文 |
| 防暴力 | 6 位随机码;3 错 → 300s 冷却;常时比对(时序侧信道) |
| 防冒名 | 同意门:被连接方人工放行后才生成码 |
| 即焚 | 连接断开码作废;B 取消等待码作废 |

## 4. 发现层

签名先行(失败不耗重放槽)→ ±10min 时间窗 → nonce 去重(4096 容量溢出拒新);身份冲突检测(data/ 被复制到另一台机器 → warn)。

## 5. 中继面(服务器)

| 机制 | 值 |
|---|---|
| PSK 准入 | TLS exporter 绑定连接 + 恒时比较;错误 5 次/60s/IP → 拉黑 10min |
| 占有证明 | ServerNonce 挑战 + sign(fp‖nonce);声明指纹必须等于证书哈希 |
| 严格启动 | 配置缺失/损坏/psk<16 → 拒绝启动(不再回退 dev-psk) |
| 资源上限 | 并发控制连接 ≤512(全局)/≤8(单 IP);读 10s 超时;推送 3s 超时;帧 ≤64KB |
| Punch 限速 | 10 次/60s/fp;目标隐身统一"不可达"(不泄露在线状态) |
| 数据面 | 16B 随机 token;S3 会话成员准入(非成员连 GOODBYE 也拒);载荷 ≤1500B(防反射放大) |
| 零知识 | 内层 QUIC 端到端加密,中继只见密文 |

## 6. 文件接收面

| 机制 | 实现 |
|---|---|
| 文件名净化 | 剔控制符+bidi 控制符;拒空/分隔符/`..`/Windows 保留名/尾点尾空格/>255B;**三道防线**(批流入口/MetaResp/finalize 内) |
| 路径防御 | resolve 五重(Component 拒/`:` 拒/canonicalize 前缀/symlink 拒/返回 canonical);rel_dir 逐段 sanitize_component |
| 偏移扩展 | MetaResp total_size 与 OfferFile.size 交叉校验(P0-4) |
| 大目录 | list_dir >50000 拒;分页 200/页;远程递归 ≤32 深/≤10000 文件 |
| 传输校验 | 逐块 SHA-256;finalize 前 missing 校验;sync_all 强制刷盘 |
| 删除门 | DeleteAsk 确认(超时/拒绝/通道关 = 不删);并发 Semaphore(8) |
| oracle 防护 | 拒绝 Offer 时回空秒传位图,不回显 hash(A5:防止探测接收方已有哪些文件) |
| 浏览探测防护 | 无 browse 权限回**空列表**(非错误,不泄露共享区存在性) |

## 7. 传输面资源纪律

- BufferPool 32×4MiB = 128MiB 在途硬上限(BufferGuard RAII 防 abort 泄漏)。
- 高频进度事件 try_send 可丢;终态 await 保证送达。
- 路由器主循环绝不 await 用户决策(Ask 等待独立子任务 + 超时)。
- 持写锁绝不 await(M-C5);锁临界区取数据后出锁再 await。

## 8. 隐私

| 项 | 纪律 |
|---|---|
| 日志 | 指纹前 8 hex;明文文件名/路径/IP 不进 tracing;秒传日志 hash 前 8 位;relay PSK 只打 sha256 摘要 |
| UI 错误 | friendlyError 脱敏(盘符/UNC → 主文件名),不回显内部绝对路径 |
| 剪贴板 | 复制 IP 45s 后自动清空(A7) |
| 分发 | dist zip 不含 data/(identity.key 是私钥);GitHub Release 只传 APK/zip |
| 前端 | CSP 收紧(default-src 'self');usesCleartextTraffic=false |

## 9. 并发与状态安全

- 会话表删除代次校验(M-B1:新一代连接不被旧代清理误删)。
- ctrl_loop 取消安全纪律(read 单次完成 + inbuf 累积,禁 select 内 read_exact)。
- 占位任务可取消(对端离线不挂死 UI,BUG01);prepare_shutdown 5s 封顶。
- RPC msg_id 多路化 + 超时 cancel 防泄漏(M-B5)。
- 会话条目丢失时配对兜底写信任(BUG03 根因修复)。

## 10. 已知残留风险(如实记录)

- PunchResp 等待者"取第一个"匹配(并发多目标 punch 可能错配)——待 per-target 索引。
- 中继学习表无 TTL(靠 GOODBYE + 2×TTL 回收)。
- 自签证书体系无吊销机制:私钥泄露只能换身份(重配对)。
- 配对码 6 位数字,熵有限 —— 靠"同意门 + 3 错冷却 + 局域网/B 屏显码"组合缓解;跨网经中继的配对同机制。
