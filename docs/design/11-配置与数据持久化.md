# 11 配置与数据持久化

> 源码:`crates/localtrans-core/src/store.rs`(254 行)、各持久化点。

## 1. data/ 目录(PC:exe 旁;Android:filesDir/localtrans)

```
data/
├── config.json            主配置
├── identity.key           Ed25519 私钥(PKCS#8 DER)—— 绝不能进分发产物
├── cert.der               自签证书(指纹来源)
├── trusted_peers.json     信任表
├── transfers.json         传输历史(双端同格式,job_id 为 16 位 hex 字符串)
├── probe_targets.json     发现重探目标(Vec<SocketAddr 字符串>)
├── logs/localtrans.log.YYYY-MM-DD   按天滚动
├── .localtrans-inbox-index.json     秒传索引(下载根,实为 download_dir 下)
└── downloads/             默认下载目录(config.download_dir 默认 = exe 目录/downloads)
    └── .localtrans-parts/{job_id:016x}/   断点 parts(恒在下载根)
        ├── part.bin
        └── manifest.json
```

**注意**:首启默认初始化(BUG07 已实现):config.json 不存在或损坏重置时,`fresh_config` 默认 `download_dir = <exe目录>/downloads`、`shares = [{alias:"共享文件夹", path:<exe目录>/share}]`,两目录自动 create_dir_all;基准取 data 目录父目录(PC 便携=exe 目录,Android FFI=filesDir)。存量配置(shares 为空也不补)不覆盖用户选择。

## 2. Config 全字段(store.rs L8-56)

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| device_name | String | `%COMPUTERNAME%` / "我的电脑" | FFI 壳覆写"我的手机" |
| download_dir | PathBuf | exe 目录/downloads | 另存为不受此限(BUG06 后任意绝对路径) |
| hidden | bool | false | 隐身 |
| quic_port | u16 | 47601 | 数据面 |
| discovery_port | u16 | 47600 | 发现 |
| shares | Vec<ShareDef> | **空** | {id, alias, path} |
| relay_enabled | bool | false | |
| relay_server | String | "" | host:port |
| relay_psk | String | "" | ≥16 字符 |
| consent_timeout_secs | u64 | 60 | 同意门超时(壳层 clamp 15-600) |
| offer_timeout_secs | u64 | 60 | 推送确认超时(clamp 15-600) |

## 3. 加载/保存策略(load_config L66-96)

| 情形 | 行为 |
|---|---|
| 文件存在且合法 | 直接加载 |
| JSON 损坏(M-B2) | **rename 备份为 `config.json.corrupt-<unix_ts>`** → 重置默认落盘;备份失败(占用)→ 内存默认不覆盖 |
| NotFound | 生成默认并落盘(首启) |
| 其他读错误(权限) | 内存默认,**不回写**(防覆盖真实配置) |

`save_config`:pretty JSON。**atomic_write**(identity/trust/config 共用):写 `<name>.tmp` → rename(失败回退 copy)。

其余持久化文件损坏策略:trusted_peers → warn+空表;probe_targets → 空集;inbox-index → 空索引(秒传退化);transfers.json → 空历史。**全部不阻断启动**。

## 4. transfers.json(传输历史)

- 双端同格式:job_id 序列化为 16 位 hex 字符串(serde_compat u64_hex_string,JS 大整数精度)。
- 壳层 1s 脏标记循环原子写;done/failed 历史封顶 **150 条**。
- 启动迁移:active/pending/paused → interrupted;push 方向或有 parts 目录的保留;孤儿接收任务丢弃。
- GC:gc_stale_parts(位图全真孤儿删/mtime>7 天删)。

## 5. 隐私红线(持久化相关)

- identity.key/cert.der 是设备身份私钥 —— **dist 分发 zip 绝不含 data/**。
- 日志:指纹只打前 8 hex;文件名/路径/IP 不进 tracing(秒传日志只打 hash 前 8 位);relay PSK 只打摘要。
- git 历史邮箱重写等清理:推送 GitHub 后执行(记忆 github-release-cleanup-pending.md)。
- 错误信息不回显内部绝对路径(UI 层 friendlyError 脱敏:盘符/UNC → 主文件名)。
